## Key decisions

- **D-024 (commit 0c206c9 v `icc-knowledge`):** Phase D Multi-Customer Pilot Architecture — per-customer compose, single-level subdomain `<slug>.isnex.eu`, manual approval per deploy, sidecar postgres-exporter, restic dual-repo backup. 5 alternatives rejected.
- **AG Grid Community vs Enterprise** — chose Community + client-side virtualization for pilot. Enterprise Server-Side Row Model deferred until customer count > 100.
- **Single-blob IndexedDB layout** — per-row store killed write at 70s for 255k records; switched to single JSON string per catalog (write <500ms, read 1-2s).
- **In-memory store** namiesto pure IDB-first — eliminuje JSON.parse(80MB) pri každej navigácii medzi modulmi.
- **JS Theming API** namiesto legacy CSS class — v AG Grid v33+ je class-based theming nespoľahlivé.
- **Filter default `startsWith`** — NEX Genesis convention; user explicitne klikne „Obsahuje" v dropdown-e.
