   - **Problem:** CSS override `.ag-floating-filter-input { border-radius: 4px }` v `964674a` nefungoval — selector cieli na wrapper `<div>`, nie na samotný `<input>` (`.ag-input-field-input`).
   - **Fix:** AG Grid v35 JS Theming API parametre `borderRadius: 4` + `wrapperBorderRadius: 4` v `themeBalham.withParams({...})`. Odstránený nefunkčný CSS override + `--radius-input` token (mŕtvy, žiadny consumer).
   - **Prečo nie CSS so správnym selectorom:** theme params aplikujú konzistentne na všetky AG Grid inputs + popups + buttons, jeden zdroj pravdy. Forward-compatible voči AG Grid upgradeom.

3. **Feature — Row cursor (commit `3a77be4`)**
   - **Director request:** šípky majú posúvať row highlight (kurzor), nie scrollovať tabuľku; mouse hover NEMÁ highlight; pri strate focusu modrá → sivá (inactive state); init kurzor na prvom riadku.

     - Odstránený `suppressCellFocus` (potrebné pre cell focus events)

     - `.ag-root-wrapper:not(:focus-within) .ag-row.ag-row-selected { background: var(--color-border-subtle) }` — inactive state cez `:focus-within` selector (AG Grid theming API natívne nepodporuje)

## Key decisions

- **Token mechanism: Tailwind v4 `@theme`** namiesto plain CSS `:root` vars — Tailwind v4 generuje utility triedy + JS-readable CSS premenné z jedného source. Aligned s D-008 (Tailwind v4 standard).
- **Border-radius cez AG Grid theme params**, nie cez CSS override — AG Grid theming API je oficiálna cesta, robustná voči upgrade-om, aplikuje konzistentne. Token `--radius-input` zmazaný (mŕtvy).
- **Row cursor = selection follows keyboard navigation**, nie samostatný "focused row" indicator — jeden vizuálny stav, jednoduchý mentálny model. NEX Genesis pattern, na ktorý sú zákazníci zvyknutí.
- **Žiadny mouse hover highlight** — keď je kurzor (selected row) vždy viditeľný a sleduje šípky, hover je redundant signál.
- **Inactive selection state cez CSS `:focus-within`** — AG Grid theming nemá natívny param pre "grid lost focus"; CSS-only riešenie je cleanest. Všetky moderné browsery podporujú `:focus-within` od r. 2017.
- **Init kurzor na prvom viditeľnom riadku** — user vidí "kde je" hneď, bez nutnosti klikať. Cez `onFirstDataRendered` (po aplikácii prípadného persisted filtra).
